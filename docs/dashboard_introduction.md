# NEXTRADE 시장운영 DASHBOARD 소개

## 한눈에 보는 서비스

NEXTRADE 시장운영 DASHBOARD는 NXT와 KRX의 가격·거래량·거래대금, NXT 매매체결대상 변동, 상·하한가 근접 종목과 KRX 시장조치를 한곳에서 확인하는 시장 모니터링 페이지입니다. 장중 현황과 2025년 3월 4일 이후의 확정 일별 데이터를 같은 기준으로 연결해, 현재 상황 확인과 과거 추이 분석을 함께 지원합니다.

## 주요 화면

### NXT DASHBOARD

- NXT 전 종목의 NXT·KRX 현재가와 누적 거래량·거래대금을 비교합니다.
- 시장별 합계와 NXT/KRX 거래비율, 주요 지수·선물·환율을 함께 보여줍니다.
- 거래불가 종목은 사유와 거래가능시장을 표시하고 NXT 시세·비율 계산에서 제외합니다.

### NXT 상·하한가 근접 종목 현황

- 시가·고가·저가·종가 중 하나가 상한가 아래 또는 하한가 위 0~3틱 범위에 진입한 종목을 찾습니다.
- 가격대별 호가가격단위를 반영해 잔여틱을 계산하고, 확인 가능한 경우 최초 도달시점을 표시합니다.
- 0틱은 상·하한가 기록 종목, 1~3틱은 순수 근접 종목으로 구분합니다.

### NXT 정규시장 종목 변동내역

- 시장 개설일의 최초 10종목부터 편입·편출과 변경사유를 일별로 관리합니다.
- 거래불가 지정·해제는 편입·편출과 분리해 별도 현황으로 제공합니다.
- 공식 변동내역이 없는 상장폐지·누락 사례는 일별 대상 명단과 공식 안내를 대사해 보완합니다.

### NXT·KRX 일별 거래 추이

- NXT·KRX 거래량과 거래대금, 거래비율을 일별로 비교합니다.
- 최근 6개월 일평균과 월말 기준 6개월 누적 거래량비율을 제공합니다.
- 2025년 4월 1일을 100으로 둔 NXT 참고지수와 KRX TMI를 함께 확인할 수 있습니다.

### KRX 시장조치 조회

- NXT 매매체결대상 종목과 관련된 KIND 공시를 기간·유형별로 조회합니다.
- 거래정지, 관리종목, 투자경고·위험, 단기과열 등 시장조치 원문과 당시 NXT 거래가능 상태를 함께 제공합니다.

## 데이터 운영 방식

- 장중 데이터는 API 호출 제한을 고려해 전 종목을 나누어 순차 수집합니다.
- 확정 일별 데이터는 NXT 공식 시세와 KRX OPEN API 등을 SQLite에 저장해 재사용합니다.
- 일일 저장 작업은 데이터 제공처의 익일 갱신 시각에 맞춰 오전 8시에 실행하며, 실패하면 1분 간격으로 최대 10회 재시도합니다.
- 여러 사용자가 접속해도 공용 수집기와 호출 간격 제어를 사용해 중복 호출을 줄입니다.

## 이용 시 참고사항

이 페이지는 시장 운영과 데이터 점검을 돕기 위한 참고 도구입니다. 장중 값은 종목별 수신 시각이 다를 수 있고, 일부 합계·지수는 제공 API의 단위와 범위에 따라 공식 거래소 통계와 차이가 날 수 있습니다. 중요한 판단이나 대외 보고에는 반드시 NXT·KRX·KIND 원문과 공식 확정 통계를 함께 확인해야 합니다.

## 짧은 소개 문구

> NEXTRADE 시장운영 DASHBOARD는 NXT와 KRX의 장중 거래 현황, 과거 거래 추이, 종목 변동과 시장조치를 통합 조회하는 모니터링 도구입니다. 전 종목 비교부터 상·하한가 근접 종목, 거래불가 및 편입·편출 이력까지 한 화면 체계에서 확인할 수 있습니다.
