# KIS 실시간 거래 현황 설정

## 1. API 키 등록

KIS Developers에서 Open API 서비스를 신청하고 App Key와 App Secret을 발급받습니다. 로컬 실행 시 `.streamlit/secrets.toml.example`을 `.streamlit/secrets.toml`로 복사한 뒤 다음처럼 입력합니다.

```toml
KIS_APP_KEY = "발급받은 App Key"
KIS_APP_SECRET = "발급받은 App Secret"
```

운영 환경에서는 같은 이름의 비밀 설정 또는 환경변수를 사용합니다. 실제 키가 들어 있는 `secrets.toml`은 Git에 포함하지 않습니다.

## 2. 관심종목

실시간 거래 현황 페이지의 **관심종목 설정**에서 한 줄에 한 종목씩 입력합니다.

```text
005930 삼성전자
000660 SK하이닉스
```

KRX와 NXT 체결 채널을 종목마다 각각 하나씩 사용하므로 최대 20종목으로 제한합니다.

## 3. 표시 및 계산 기준

- NXT 거래량·거래대금: NXT 당일 누적 합계
- KRX 거래량·거래대금: 정규시장 당일 누적 합계
- 거래대금 단위: 원
- 등락률: `NXT 현재가 / 기준가격 - 1`
- 괴리율: `NXT 현재가 / KRX 현재가 - 1`
- 거래량비율: `NXT 거래량 / KRX 거래량`
- 거래대금비율: `NXT 거래대금 / KRX 거래대금`

KIS NXT 체결의 현재가와 전일대비로 기준가격을 복원합니다. NXT 기준가격을 얻을 수 없는 경우에는 KRX 체결에서 복원한 전일종가를 사용합니다. KRX 현재가가 아직 수신되지 않았거나 분모가 0이면 해당 괴리율 또는 비율은 `-`로 표시합니다.

거래량과 거래대금은 KIS 실시간 체결의 `ACML_VOL`, `ACML_TR_PBMN` 누적값 증분으로 집계합니다. NXT 누적값이 세션 전환 시 초기화되는 경우도 자동으로 처리합니다.

## 4. 데이터 품질 상태

- **정상**: 첫 장 구간부터 연속 수집한 값
- **부분**: 앱이 장중에 처음 시작됐거나 연결 공백이 장 구간 경계를 넘은 값
- **대기**: 아직 해당 종목 체결을 받지 않은 상태

앱을 장중에 처음 실행하면 이미 지나간 NXT 세션의 누적값을 정확히 분리할 수 없습니다. 수집 중 같은 장 구간 안에서 잠시 연결이 끊긴 경우 누적값 차이로 복구하지만, 연결 공백이 장 구간 경계를 넘으면 어느 구간의 거래인지 확정할 수 없어 부분 상태로 표시합니다. 이 상태는 표가 아니라 화면 상단의 연결 상태 옆에 표시됩니다.

## 5. 저장

관심종목과 당일 구간별 집계는 `data/kis_market.db`에 저장됩니다. 앱을 다시 실행하면 같은 영업일의 마지막 누적값부터 이어서 계산합니다.

## 6. REST 전종목 시세 페이지

별도 **REST 전종목 시세** 페이지는 넥스트레이드가 공개한 최신 대상 종목 전체를 가져와 KIS 관심종목 멀티시세 API로 반복 조회합니다. 한 요청에 15종목의 KRX/NXT 조합 30개를 넣고, 전체 종목을 순차적으로 갱신합니다.

화면에서 5초, 10초 또는 30초 목표 주기를 선택할 수 있습니다. 전체 호출에 목표 주기보다 오래 걸리면 호출을 겹치지 않고 직전 회차가 끝난 뒤 다음 회차를 시작합니다. 페이지를 닫거나 다른 화면으로 이동하면 불필요한 REST 호출을 막기 위해 수집기가 자동으로 일시정지합니다.

표는 NXT 거래대금 내림차순으로 정렬하며, 넥스트레이드 원본 종목 현황의 거래불가사유를 마지막 열에 표시합니다. 제목 아래의 KOSPI, KOSDAQ, KOSPI200, KOSDAQ150 카드는 KIS 국내업종 현재지수 API의 현재값, 전일대비, 등락률을 사용합니다.

종목표 위의 시장 합계는 NXT 전종목 REST 결과를 합산하고, KRX는 KIS 지수 응답의 KOSPI·KOSDAQ 누적값을 합산합니다. 지수 응답의 `ACML_VOL`은 천 주, `ACML_TR_PBMN`은 백만원 단위이므로 각각 주와 원으로 환산한 뒤 NXT/KRX 거래량비율과 거래대금비율을 계산합니다. 공식 문서에는 천주·백만원 미만 값의 반올림 또는 절사 규칙이 명시되어 있지 않아 KRX 합계는 정확한 원단위 값으로 보지 않습니다. NXT 전체 시장 합계를 직접 반환하는 KIS 전용 응답은 확인되지 않아 전종목 수집이 끝나기 전에는 NXT 합계를 부분 합계로 안내합니다.
