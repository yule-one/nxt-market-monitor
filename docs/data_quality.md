# 데이터 품질 기준

## 데이터와 grain

- NXT 거래현황 원천: `일자 × 종목코드 × 거래가능시장 × 거래불가사유`
- NXT 변동 원천: `일자 × 종목코드 × 편입/편출 × 사유`
- KIND 원천: `접수번호 × 시장조치 분류`
- KRX OPEN API 종목 원천: `기준일자 × 시장 × 종목코드`
- KRX OPEN API 지수 원천: `기준일자 × 지수명`
- 일별 지표: `일자` 1행
- NXT 선정·거래상태 요약: `일자` 1행
- NXT 선정·거래상태 사유: `일자 × 구분 × 사유`
- NXT 거래불가 일별 상태: `일자 × 종목코드`
- NXT 거래불가 지정·해제 이벤트: `일자 × 종목코드 × 구분`
- 종목 결합키: 6자리 종목코드, 불일치 시 `정규화 종목명 × 시장` 보조키

## 검증 규칙

1. NXT 종목코드는 영문 혼합 신규 코드를 포함한 6자리 영숫자여야 합니다.
2. NXT 거래현황의 일자·종목코드는 날짜 안에서 유일해야 합니다.
3. `거래가능시장`, `거래불가사유`는 NXT 원본 문자열을 변경하지 않습니다.
4. NXT 변동 유형은 `편입`, `편출`만 허용합니다.
5. NXT 이벤트 중복키는 `일자, 종목코드, 변동, 사유`입니다.
6. KIND 접수번호는 분류 안에서 유일해야 합니다.
7. KIND 시장은 KOSPI/KOSDAQ으로 정규화합니다.
8. 공시와 시장조치 집계는 해당 일자의 NXT 거래현황 종목코드와 교차합니다.
9. 우선주 대상 공시는 대표 보통주와 결합하지 않습니다.
10. 거래정지·관리·환기·단기과열 상태는 과거 공시를 누적하지 않고 해당 일자 NXT `거래불가사유`로 집계합니다.
11. 과거 시가총액은 KRX OPEN API `MKTCAP`을 사용하고, 장중 시가총액은 `KRX 현재가 × KIS 종목 마스터 상장주식수`로 계산합니다.
12. 일별 합계의 비율은 저장값을 다시 `NXT ÷ KRX`로 계산해 DB의 비율과 일치하는지 검증합니다.
13. 과거 상세 DB는 `일자 × 종목코드` 기본키로 NXT·KRX 행의 중복을 차단합니다.
14. 원본 편출 중 투자경고·투자위험·단기과열·거래정지·시가기준가 지정은 `거래불가`, 대응하는 원본 편입은 `거래불가 해제`로 재분류합니다.
15. 재분류 후 `매매체결대상종목수 = 거래가능종목수 + 거래불가종목수`와 KOSPI·KOSDAQ 시장별 합계를 검증합니다.
16. 일별 대상 명단의 전일 대비 증감과 변동 원본을 종목코드 단위로 대사합니다. 원본에 없는 편입·편출은 재등장 여부와 공식 선정·상장폐지 근거를 확인한 뒤 `nxt_membership_change_adjustments`에 별도 저장합니다.
17. 원본의 포괄적 사유는 공식 시장안내에 따라 최초·단계별 확대·분기 정기변경·거래량한도관리 등 화면용 `변경사유`로 변환하며 원본 사유는 함께 보존합니다.
18. 구형 일별 원본에서 거래제한 종목 행이 빠진 기간은 지정·해제 변동 및 해제 전 연속 누락기간으로 복원하며, 보정 행을 별도 테이블에 보관합니다.
19. 거래불가 일별 상태는 거래현황의 `거래가능시장=거래불가` 행을 우선하며, 원본에서 행이 빠진 구형 구간만 변동내역 기반 보정 행을 사용합니다.
20. 거래불가 지정은 전 거래일 비거래불가→당일 거래불가, 해제는 전 거래일 거래불가→당일 거래가능 상태일 때만 생성합니다. 종목 자체가 명단에서 사라진 경우에는 거래불가 해제로 만들지 않습니다.
21. 시장 개설일인 2025-03-04의 최초 10종목은 `최초` 사유의 편입으로 집계합니다. 조회기간 순증감은 기간 내 일별 편입 합계에서 편출 합계를 빼서 계산합니다.

## KRX 거래량·거래대금 범위 검증

- KRX OPEN API 유가증권·코스닥 일별매매정보는 `basDd`만 입력받고 세션코드는 받지 않습니다. 개발 명세의 원천 질의도 일별 누적 `ACC_TRDVOL`·`ACC_TRDVAL`을 조회하며 별도 세션 조건이 없습니다.
- 따라서 과거 개별종목 값은 정규장 일반매매뿐 아니라 정규장 대량·바스켓, 시간외 종가·단일가·대량·바스켓 매매를 합산한 확정 일별 누적값으로 사용합니다. 정규시장 G1만 분리할 수 없습니다.
- 종목 일별매매정보의 대상 증권그룹에는 `ST`와 `DR` 등이 포함됩니다. 즉 개별종목 API에는 외국주권·DR 행이 포함됩니다.
- 대시보드의 KRX **시장 합계**는 전종목 행 단순합이 아니라 KOSPI·KOSDAQ 대표지수 행의 누적값입니다. 2025-03-04, 2025-12-30, 2026-08-05를 대사한 결과 전종목 합계와 대표지수 합계의 차이가 각 날짜의 외국주권·DR(단축코드 900xxx·950xxx) 합계와 거래량·거래대금 모두 정확히 일치했습니다. 따라서 시장 합계에는 외국주권·DR이 포함되지 않습니다.
- KRX는 정규장과 시간외장을 별도로 운영하고 정규장·시간외 대량/바스켓 매매를 모두 공식 거래 방식으로 규정합니다. 데이터 마켓플레이스도 당일 정규시장 값과 시간외를 포함한 당일 전체 매매내역의 제공 시각을 구분합니다.

## 알려진 제한

- NXT 거래현황은 비거래일에 행을 반환하지 않으므로 일별 추이와 KRX 시장조치 표는 원본 행이 있는 날짜만 표시합니다.
- NXT의 `거래불가사유`가 세부 시장조치 유형을 충분히 구분하지 못하는 경우 KIND 분류와 결합합니다.
- KIND 제목에 효력일이 없는 지정/해제 공시는 당일공시 수에만 반영하고 상태 누계에는 사용하지 않습니다.
- 투자경고·투자위험 상태는 KIND 투자주의/경고/위험 현황의 지정일과 해제일을 사용합니다.
- 거래정지·관리종목·투자주의환기·단기과열은 NXT가 공개한 당일 `거래불가사유`를 KIND 상태의 보완 근거로 사용합니다.
- 최근 공시는 정정될 수 있으므로 캐시 만료 후 재수집 시 과거 수치가 변경될 수 있습니다.
- NXT 원본이 투자경고와 투자위험을 `투자경고/위험`으로 합산 표기하므로 두 사유는 별도 분리하지 않습니다.
- KIND 화면에 표시된 일부 보조 분류 코드와 실제 반환 제목이 일치하지 않는 사례가 있어, 거래정지/재개는 실데이터 검증이 된 일반 주권 코드 `0311`을 사용합니다.
- 거래불가 이벤트의 KIND 원문은 종목코드, NXT 사유, 지정·해제 방향, 이벤트일 이전 20일 이내 공시를 함께 검증합니다. 단기과열 해제는 별도 해제 공시가 없을 때 `3거래일 단일가매매` 지정 공시를 기간 종료 근거로 사용합니다.
- 위 조건으로 확정할 수 없는 거래정지·시가기준가 등 19행은 오연결을 피하기 위해 KIND 공시와 원문을 빈칸으로 표시합니다.
- KRX OPEN API 일별매매정보는 G1 전용 값을 제공하지 않습니다.
- 과거 KRX 시장 합계는 외국주권·DR을 제외한 KOSPI·KOSDAQ 대표지수 누적값이며, 개별종목 일별매매정보의 전 종목 단순합과 다릅니다.

## 자동 테스트 대상

- 종목코드 정규화
- KIND HTML 파싱 및 접수번호 유일성
- NXT 거래현황 JSON 파싱과 원본 컬럼 보존
- NXT 변동 JSON 파싱과 허용값
- 편입→편출→재편입 상태 재구성
- 날짜별 NXT 공식 유니버스와 공시 결합
- 우선주 공시 결합 차단
- 지정/해제 상태 전이
- 거래불가 지정·해제 재분류와 실제 편입·편출 분리
- 거래불가 일별 상태와 지정·해제 이벤트 기본키 유일성
- 거래불가 종목의 명단 편출을 거래불가 해제로 오인하지 않는 상태 전이
- 일별 매매체결대상·거래가능·거래불가 합계 및 사유별 합계 대사
- 전일·당일 대상 명단 증감과 원본·보정 변동내역 대사
